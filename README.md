# 九命 · Nine Lives

一个猫奴为救小猫被大运卡车撞死，醒来时成了那只猫。城市不会因为你是"人"就对你宽容——你有九条命，一条比一条难活。

**在线试玩**：https://kekekecola.github.io/ninelives/

## 这是什么

一份独立完成的原创游戏概念策划（光核共创营 · 课题九）。全部内容——世界观、玩法、角色、像素画面、代码——都在一个 HTML 文件里，零依赖、离线可开。

打开后往下滚，先玩一小段「雨夜巷子」，再看这套设计为什么这么做。

## 玩法

- `W A S D` / 方向键移动，靠近东西按 `E` 互动，手机用左下角摇杆
- 遇到老鼠会进入回合制对决：炸毛威吓、撕咬、贴地躲开，或者把鱼让出去
- 学会哪一招取决于路上认识了谁——白手套教你威吓，断尾教你走夜路
- 死一次少一条命，活下来不扣；技能和走过的路会留到下一夜

## 技术

单文件 Canvas 像素渲染，320×180 内部分辨率，程序化绘制全部画面与角色，没有任何外部素材与依赖。内置 76 项自动自检（在网址后加 `?selftest=1` 可以自己跑）。
